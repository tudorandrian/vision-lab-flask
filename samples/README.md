# Sample image

`astronaut.jpg` is the official NASA portrait of astronaut Eileen Collins. As a work of NASA it is
not subject to copyright in the United States (protection elsewhere is less clear). The file was
taken from scikit-image 0.25.2 (`skimage/data/astronaut.png`), where it is a standard test image,
and re-encoded as JPEG at quality 88.

Eileen Collins is an identifiable person. NASA's media usage guidelines ask that such images are
not used commercially without her permission and that no use implies endorsement by NASA or by
her. This project uses the image for education and testing only.

It is used by `pytest -m models`, by the browser tests, by `scripts/smoke_load.py` and for the
screenshots in the README. It is not used to demonstrate facial expression analysis.
