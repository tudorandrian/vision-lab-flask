# Sample image

`astronaut.jpg` is the official NASA portrait of astronaut Eileen Collins. NASA imagery is in the
public domain. The file was taken from scikit-image 0.25.2 (`skimage/data/astronaut.png`),
where it is a standard test image, and re-encoded as JPEG at quality 88.

It is used by `pytest -m models`, by the browser tests, by `scripts/smoke_load.py` and for the
screenshots in the README. It is not used to demonstrate facial expression analysis.
